# Puma Website

This is a front-end clone of the official Puma website built using **HTML** and **CSS**.  
The project was created for practice purposes to improve my web development skills.

## 📌 Project Overview

This project replicates the UI/UX of the Puma official website. It focuses on layout design, responsiveness basics, and styling using CSS.

## 🚀 Features

- Homepage layout similar to Puma website
- Navigation bar design
- Product showcase sections
- Banner and hero sections
- Footer design
- Responsive styling (basic)

## 🛠️ Built With

- HTML5
- CSS3
